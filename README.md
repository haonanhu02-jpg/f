# 档案台账系统

采用前后端分离：React/TypeScript前端、独立Node.js后端、SQLite数据库。软件1.0.0已具备档案登记与编号、扫描附件、Excel导入导出、账号权限、日志、到期提醒和统计；第六阶段提供Linux内网部署包及备份恢复工具，实际服务器上线待提供地址、域名/证书和连接信息。

## 第一阶段资料

从[第一阶段交付清单](docs/phase-1/README.md)开始阅读。其中列明业务规则、字段字典、分类与编号、公司目录及待补事项。

用户已确认：普通类别按公司＋档案大类＋分类路径连续编号；原表标注年份流水号的类别按年重新编号。现行证照放资质类，历史版本放文书类，同一份档案只登记一次。

用户要求美国万盛、英国万盛、济宁汉峰国际贸易有限公司的公司编码，以及秘密等级暂标为待补。原始公司简称也缺少的，随编码一起保留空值。

原表没有明确的细节已标为实现建议或待明确，不视为用户已逐项确认。后续开发应保留这些区别。

## 生产运行与Linux交付（第六阶段）

当前按用户要求采用Linux容器方式：项目根目录 [deploy.sh](deploy.sh) 从指定GitHub仓库拉取代码，依次尝试多个代码/基础镜像/npm源，构建并通过Docker Compose启动。成功输出网站链接；失败输出日志目录及前30行日志。执行方式和配置见[容器部署说明](deploy/docker/README.md)。main分支包含Dockerfile、部署脚本和vendor构建依赖。

```bash
sudo bash deploy.sh
```

默认开放内网8080端口并识别服务器IP，可通过 PUBLIC_URL、HTTP_PORT 调整。SQLite及附件保存在Docker命名卷，重复部署前先备份，更新不删除数据卷。当前已完成脚本验证，尚未在目标服务器完成真实容器启动。

目标为Linux公司内网服务器、多人访问。交付内容见[第六阶段清单](docs/phase-6/README.md)。原[systemd部署说明](deploy/linux/README.md)作为备用方案保留，不与容器应用同时启用。delivery/ 中的既有1.0.0运行包面向原Node宿主机部署；本次容器源码包另行提供，不含工作数据及默认账号密码。

在本机已有依赖时，可先构建并运行相同的生产程序：

```powershell
cd D:\档案\frontend
npm run build:production
```

再从项目根目录启动（先停止原3001开发后端，避免两套界面同时操作工作库）：

```powershell
cd D:\档案
node scripts/start-production.mjs
```

访问`http://127.0.0.1:8080/`。这个入口使用 backend/data/archive.sqlite，不运行前端开发服务器。本机地址只供当前电脑访问；公司多人访问通过服务器Nginx HTTPS入口，实际地址待部署后确定。

使用者操作见[使用手册](docs/phase-6/使用手册.md)，日常备份、恢复、升级回退见[运维说明](docs/phase-6/运维与恢复.md)。服务器上线检查见[验收清单](docs/phase-6/验收清单.md)，未执行的检查保留待验收状态。

## 开发运行方式

需要Node.js 24或更高版本。后端和前端分别启动：

```powershell
cd D:\档案\backend
npm ci
npm start
```

另一个终端：

```powershell
cd D:\档案\frontend
npm ci
npm run dev
```

已安装依赖后无需每次执行npm ci。打开`http://127.0.0.1:5173/`，独立后端为`http://127.0.0.1:3001`，数据库为`backend/data/archive.sqlite`。

首次打开请自行创建管理员账号，项目没有默认账号密码。管理员随后维护实际秘密等级并建立其他账号，按公司、密级及附件/导出能力授权。秘密等级初始为空，未定密资料也需单独授权。

现行编号格式已确认：GF-ZZ-001、GF-WS-01-01-001、GF-WS-20-2026-001，年份由录入人选择归档年份。正式档案可以修改保管等信息；归属、分类与年份锁定；作废保留原号且不复用。

权限、日志、提醒和统计详见[第五阶段完成清单](docs/phase-5/README.md)及[第五阶段API](docs/phase-5/API.md)。附件和Excel操作见[第四阶段说明](docs/phase-4/README.md)，登记编号见[第三阶段说明](docs/phase-3/README.md)，运行配置见[后端说明](backend/README.md)。
