## 首次使用

1. 按[项目启动说明](../../README.md)启动后端和前端，打开 <http://127.0.0.1:5173/>。
2. 数据库尚无账号时，页面显示创建首位管理员。自行填写登录名、姓名和密码；项目没有默认账号密码。登录名为3—50位小写字母、数字、点、下划线或短横线，以字母开头，密码为10—128位。
3. 管理员进入账号权限页面，先维护公司的实际秘密等级，再建立其他使用者账号。
4. 为每个普通账号选择角色、可访问公司、秘密等级，以及是否允许未定密、附件原文件访问和Excel导出。
5. 使用者登录后可在顶部修改本人密码、退出登录。修改密码后需要重新登录。

实际工作库没有写入验收账号。秘密等级仍待公司提供，不预设名称或等级高低；美国万盛、英国万盛、济宁汉峰国际贸易有限公司的编码继续待补。

## 已确认的授权规则

| 操作 | 系统管理员 | 档案管理员 | 查询人员 |
| --- | --- | --- | --- |
| 台账、提醒与统计 | 全部资料 | 授权范围 | 授权范围 |
| 新增/修改/登记/作废/附件上传/Excel导入 | 可以 | 授权范围 | 不可以 |
| 附件原文件预览和下载 | 可以 | 单独授权后可以 | 单独授权后可以 |
| Excel导出及导入结果报告下载 | 可以 | 单独授权后可以 | 单独授权后可以 |
| 基础资料、账号、秘密等级、操作日志 | 可以 | 不可以 | 不可以 |

普通账号读取一份档案，必须同时满足公司授权与秘密等级授权。等级是精确匹配，授权一个等级不会自动包含其他等级。空秘密等级代表未定密，必须另外允许访问；它不等同于公开。账号有原文件权限时，仍须满足对应档案的公司和密级范围。

附件原文件权限同时控制预览和下载。未获得该权限时仍可查看已授权档案的附件名称等台账信息。Excel导出、附件原文件分别授权。Excel导入只能使用授权公司和等级；导入任务归创建者所有，其他普通账号无法读取或确认，即使档案范围相同。

服务端逐次验证登录状态与权限，直接调用接口同样受限。停用账号、修改授权或重置密码会撤销该账号已有会话；不允许停用或降级最后一个启用的系统管理员。用户与等级修改有版本冲突校验。

## 提醒与统计口径

- 以北京时间（Asia/Shanghai）的日期计算，默认提前30天，可切换7、30、60、90天。
- 仅对已登记档案产生提醒。已过期持续显示，当天到期单独标记，未来在所选天数内显示即将到期。
- 固定有效期和固定保存期限分别计算；长期、未知、不适用日期不生成到期事项。同一档案可产生两条提醒，页面计数单位是“事项”。
- 保存期限届满仅提醒，不自动删除或作废档案。本阶段为系统内提醒。
- 统计包含授权范围内的草稿、已登记和作废档案；总数与分组口径一致。修改公司筛选后，图表和汇总一起更新。

## 日志与数据库

操作日志只向系统管理员开放，支持动作筛选和分页。修改记录展示前后内容；密码、密码哈希、会话及CSRF令牌不写入日志。历史事件保留并标注为历史记录，不补造操作者。日志在应用中只读，SQLite触发器阻止常规更新和删除；拥有数据库文件和主机管理权限的人仍能够修改数据库，不能将其视为独立的防篡改存证。

数据库结构版本升级为3，增加账号、会话、登录失败计数、秘密等级与操作日志表，为导入任务增加创建者字段。不重置已有档案、档号、计数器或附件。具体接口见[第五阶段API](API.md)。
