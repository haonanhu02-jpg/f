## 运行与查看

项目目录：`D:\档案\frontend`。

```powershell
cd D:\档案\frontend
npm run dev
```

默认打开`http://127.0.0.1:5173/`，以终端实际显示地址为准。新机器先安装Node.js 22.13或更高版本，再执行`npm ci`。

初始台账为空，用户可新增草稿或点击“载入演示数据”查看13条示例。应用运行资料保存在当前浏览器，不与其他设备同步；清理浏览器存储会删除本机资料。
