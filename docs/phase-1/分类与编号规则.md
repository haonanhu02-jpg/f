## 5. 档号拼接模板建议

以下是实现建议，**不是Excel已经给定的完整档号格式**。前期页面上的`GF-01-01-001`也只是展示样例。

为区分两大类，建议增加大类标识`ZZ`（资质）和`WS`（文书）；连接符使用半角短横线。用户已确认的是计数范围和年度规则，尚未单独确认这些可见标识、连接符和年份含义。

| 场景 | 建议模板 | 拟定示例 |
| --- | --- | --- |
| 资质类，无子分类 | 公司-ZZ-流水号 | GF-ZZ-001 |
| 文书，有固定三级 | 公司-WS-二级-三级-流水号 | GF-WS-01-01-001 |
| 文书，有更深分类 | 公司-WS-二级-三级-下级-流水号 | GF-WS-09-01-02-001 |
| 文书，直接流水号 | 公司-WS-二级-流水号 | GF-WS-02-001 |
| 文书，年份流水号 | 公司-WS-二级-年份-流水号 | GF-WS-20-2026-001 |

建议流水号最少三位，001起，超999自然增长，作废号不复用。原表并未规定所有类别的位数与溢出方式。年份建议显式选择归档年份，不能默认为发证年份，也不能擅自解释为合同签订年份。

普通固定分类同样需要流水号，避免同一分类中多份档案生成相同档号。路径只拼接实际存在的节点，缺层不补00或XXX。

## 6. 编号行为验收样例

以下以建议模板解释用户已经确认的计数行为，不是正式档号清单。

| 动作 | 预期 |
| --- | --- |
| GF下基建/规划许可证连续登记两份 | 尾号001、002 |
| GF下基建/不动产权证书首次登记 | 自己的分类范围从001开始 |
| GF下规划许可证跨年再登记 | 继续原范围下一号，不回到001 |
| GF合同类选择2026年登记两份，再选择2027年首次登记 | 2026尾号001、002；2027尾号001 |
| 另一家公司同分类首次登记 | 使用另一公司编码，尾号独立从001开始 |
| 两人同时在同一范围新增 | 获得两个不同正式档号 |
| 作废001后继续新增 | 不重新使用001 |
| 缺少公司编码的公司申请正式入账 | 明确提示先补公司编码，不分配虚构档号 |
