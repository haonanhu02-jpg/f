后续开发应以“原表事实＋D01/D02/D03”为确定需求；文档中的“实现建议”可作为设计基线，不应宣称已由用户逐项确认。与业务含义有关的未决项按例外清单处理。缺失公司编码的公司可以维护基础资料，但不能正式分配档号；秘密等级未补前不能据此上线密级权限。
