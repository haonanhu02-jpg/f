# 档案台账业务规则

版本：v1.0，2026-11-09。

## 1. 依据与标记

源表为《档案台账AI系统.xls》，包含“档案台账AI系统”和“文书档案类流水号编码规则”。现有内容是字段模板和基础目录，没有实际台账记录，不能据此计算真实库存、到期数量或附件数量。

- **原表明确**：原始单元格中直接写出的事实。
- **用户确认**：本轮用户明确认可的业务决定。
- **实现建议**：为开发提供的具体方案，可以调整，不冒充原表规定。
- **待补/待明确**：现有材料无法确定的内容。

## 2. 管理对象和归档边界

**原表明确：**每份档案选择所属公司与大类，大类为“资质类（含证书）”“文书档案类”。公司对应一级编码；文书目录继续按下级分类编码。

**用户确认：**现行证照登记在资质类，历史归档版本登记在文书类，同一份档案只登记一次。

**实现建议：**每份档案只有一个所属公司、一个档案大类、一条分类路径、一个正式档号。跨公司引用采用关联，不复制为同一份档案的多条登记。证书编号属于证照本身，不能代替系统档号。

历史版本按内容选择文书目录，例如原表“工商类/资质证书历史版本”已有明确节点。该节点与“资质证书类（21）”的精确分工尚未写清，不能把所有历史证照自动分到21类。

同一份档案转为历史归档时，建议在原记录执行归档重分类，保留旧档号、分类和变更记录，并按新编号范围生成新档号。历史档号继续可查且不复用。若换发形成另一份证照，则新建新版本并关联前一版本；这与重复登记同一份档案不同。具体变更流程仍需在台账核心功能阶段落实。

## 3. 公司与分类基础资料

1. 原表有33家公司，其中30家有编码。原始序号存在重复，不能作为系统唯一标识。
2. 公司名称、简称、编码分别保存；公司名称/简称修改不应默默改动历史档号。
3. 缺少公司编码的3家公司按用户要求保留待补，不能自行编造正式编码。
4. 文书目录表头指定“浙江万盛股份有限公司”；其他公司的分类适用范围未明确。建议采用可配置目录，由管理员对公司启用，避免直接认定全集团适用。
5. 目录支持多层级，不能强行固定为“公司＋二级＋三级”。“高管私人类”在人员下面还有“证件”“借贷纠纷资料”等下级节点。
6. 保留24个二级编码及其原始值，不把缺少的14类自动补入，也不重排15—25类。
7. `XXX`、`20XX`是原表编号提示，不作为可选择的真实分类；星号保留为来源标记，其业务含义待明确。

## 4. 录入与校验建议

以下为实现建议，原表未定义必填规则。

| 项目 | 建议规则 |
| --- | --- |
| 正式登记最低信息 | 所属公司、档案大类、档案/证件名称、适用的完整分类路径 |
| 档号 | 保存成功时后端分配；预览号不预留、不保证最终使用 |
| 证书编号 | 文本，可含字母和符号，保留前导零；相同编号提醒核查，不直接当作重复档案拒绝 |
| 数量 | 原件、复印件、扫描件分别填非负整数；空白表示未核实，0表示明确没有 |
| 发证日期 | 可空；有值时必须为有效日期，不把归档年份默认取为发证年份 |
| 有效期 | 明确选择有期限、长期有效、不适用或待核实；有期限应填写到期日，起始日可按实际资料填写 |
| 有效日期顺序 | 起止都存在时，开始日期不得晚于到期日期；不直接禁止历史或已过期证件登记 |
| 保存期限 | 有期限、长期保存、待核实；有期限应填写终止日，完整起止必须满足先后顺序 |
| 存放位置 | 先支持文本；档案室/柜/层/盒可在后续配置为结构化选项；电子档案可注明无实体原件 |
| 秘密等级 | 选项待补；可在准备录入时标为待核定，但“待核定”不代表公开，不据此开放访问 |
| 移交信息 | 姓名和部门分别保存；后续部门字典启用时保留历史显示值 |
| 扫描件数量 | 按原表份数登记，不默认等于上传文件数；一个PDF可包含多份材料 |
| 附件 | 关联具体档案；数量、预览、下载和权限在附件阶段实现 |
| 备注 | 保存业务说明，不作为编号、权限或有效期判断的替代字段 |

分类不适用的字段显示为不适用，不要求普通文书填写虚构的发证单位或证书日期。发证日期与有效期起始日期不是同一字段，二者不能强制相等。

## 5. 编号分配与变更

**用户确认：**普通类别的计数范围为“公司＋档案大类＋完整分类路径”，持续递增；原表标注年份流水号的类别，在上述范围内再按年份分别计数。

**实现建议：**计数由后端统一管理，档号设置唯一约束；并发新增、接口重试、批量导入均不得产生相同正式档号。失败/回滚不得遗留半条台账；流水号可有空缺，不要求无缝连续。

普通编号至少三位，`001`起；超过`999`后自然增长到`1000`，不循环覆盖。三位流水号由原表部分分支明确给出，其他分支采用相同最小宽度属于实现建议。

作废保留记录、原因及历史编号，不复用编号。已编号记录的公司、大类、分类路径、编号年份变更建议使用专门流程，保留变更前后值，不做无痕覆盖。普通内容修正不改变档号。

年份取“归档年份”并在录入时显式选择，属于本版建议，原表只写了“年份流水号”，没有指定年份来源。编号模板在[分类与编号规则.md](分类与编号规则.md)中单独列出。

## 6. 第一版范围

确定需求覆盖：公司、分类、台账字段、编号规则、查询和导入导出需求。已认可的界面作为第二阶段视觉方向。

扫描件管理、到期提醒、角色权限、操作日志为后续阶段计划。秘密等级须预留字段，但本阶段不宣称已有密级策略。AI识别与自然语言检索留作后续扩展，Excel文件名中的“AI”不等于已定义相应功能。
