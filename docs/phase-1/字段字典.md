# 字段字典

## 1. 标记与通用约定

字段英文名是开发建议，原表中文名称及来源保留。下表“必填”均为本版建议，Excel本身未定义必填。字符串编号保留前导零；日期用日期类型，数量用整数；空值与零分开存储。

源表简称：T＝“档案台账AI系统”；R＝“文书档案类流水号编码规则”。

## 3. 原表说明/编码表要求的字段

| 字段 | 建议系统字段 | 类型 | 来源和规则 |
| --- | --- | --- | --- |
| 所属公司 | company_id | 公司关联 | T!A4说明要求；必填，匹配R!B4:D36，公司编码单独保存 |
| 档案大类 | archive_group | 枚举 | T!A4；必填，仅资质类（含证书）、文书档案类 |
| 二级分类 | category_level2_id | 分类关联 | 文书目录R!G5:AV6；文书类按适用目录选择 |
| 三级及更深分类 | category_path_ids | 分类路径 | R!G7:AV10；按真实层级保存，不把XXX/20XX当作分类 |
| 正式档号 | archive_number | 唯一文本 | T!A4的自动流水号要求；后端分配，与证书编号不同 |
| 流水号数值 | sequence_number | 正整数 | 自动生成；显示时按模板补零 |
| 编号年份 | numbering_year | 年份整数/空 | R!T7、AQ7、AT7、AU7提示；普通连续类为空，年份类必填；年份来源待明确 |

## 4. 实现建议新增字段

| 字段 | 建议系统字段 | 用途 |
| --- | --- | --- |
| 内部ID | id | 稳定唯一标识；与序号、档号分别管理 |
| 有效期模式 | validity_mode | 有期限/长期有效/不适用/待核实；这是期限状态，不是秘密等级 |
| 保存期限模式 | retention_mode | 有期限/长期保存/待核实；原表未指定固定保存年限 |
| 记录状态 | record_status | 准备录入、正式登记、作废等流程状态；详细流程在核心功能阶段落实 |
| 附件关联 | attachments | 一份档案对应多个文件，附件数独立统计 |
| 前一版本 | previous_version_id | 换发或新版本关联，避免重复登记同一份材料 |
| 历史档号 | historical_archive_numbers | 归档重分类等场景下保留旧档号与变更原因 |
| 创建/修改信息 | created_at、created_by、updated_at、updated_by | 操作追溯；具体日志在后续阶段实现 |
| 有效期状态 | validity_status | 动态计算，不由人员手填；到期提醒阈值后续确定 |
| 保存期限状态 | retention_status | 动态计算；届满提醒不等于自动删除或销毁 |

## 6. 验收例子

- 数量为`0`和空白应显示不同含义，导入导出不互相替换。
- 证书编号`00123`保存后仍为`00123`。
- 普通文书可以没有证书编号、发证单位、证件有效期。
- 长期有效的记录不应因为到期日为空而显示已过期。
- 保存期限与证件有效期可以不同，任何一组都不覆盖另一组。
- 同一证书编号出现在不同版本时，应能核查版本关系，不能只靠编号判定重复。
