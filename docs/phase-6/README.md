## 发布与校验

在开发电脑执行前端类型检查与生产构建、后端测试、生产页面验收，再运行 scripts/package-release.py 生成 delivery/ 下的Linux运行包及源码包。运行包附带纯JavaScript后端依赖和已构建页面，不含工作数据库、备份、账号凭据或开发依赖；Linux服务器无需重新构建前端，也无需下载npm依赖。

包内 RELEASE-MANIFEST.json 列出每个文件的大小及SHA-256；外层zip另有同名.sha256文件。文件校验用于发现传输损坏，不替代组织对安装包来源的管理。包内 tools/verify-release.mjs 可在Node.js 24上验证全部交付文件。

现有33家公司和分类继续保留，三家公司编码及公司秘密等级仍待实际资料补齐。当前工作库不创建默认账号，部署包也不附带工作库；首次服务器启动需通过页面创建管理员。若需迁移当前工作库，单独制作校验备份并按恢复步骤迁入。

生产构建依据[Vite官方构建说明](https://vite.dev/guide/build.html)，在线快照采用[Node.js 24 SQLite备份API](https://nodejs.org/download/release/v24.15.0/docs/api/sqlite.html#sqlitebackupsource-db-path-options)。
