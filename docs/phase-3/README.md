## 运行方式

使用Node.js 24或更高版本。首次分别在backend、frontend目录执行npm ci。

后端终端：

```powershell
cd D:\档案\backend
npm start
```

前端终端：

```powershell
cd D:\档案\frontend
npm run dev
```

浏览器地址为`http://127.0.0.1:5173/`。数据库默认`backend/data/archive.sqlite`，不再依赖浏览器保存正式资料。当前按本地开发运行，未发布网站。
